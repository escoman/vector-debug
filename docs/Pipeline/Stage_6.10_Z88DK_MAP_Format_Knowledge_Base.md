# Stage 6.10 — Z88DK MAP Format Knowledge Base

## Цель

Добавить в Knowledge Base точное описание формата `.map`-файлов, используемых **Z88DK**, чтобы AI Agent при анализе и генерации MAP-файлов использовал реальный формат Z88DK и не придумывал собственный формат.

Этап касается только документации и знаний AI Agent.

Не изменять:

```text
src/
Agent API
MCP protocol
DebugBackend
DebugAdapter
Board
```

```text
debugger/agent/knowledge/vector06c/z88dk_map.md
```

Документ должен описывать именно формат MAP, который реально генерирует и использует Z88DK.

# 2. Источник истины

Иерархия источников:

```text
Z88DK implementation (исходный код генерации MAP)
        ↓
реальные MAP-файлы
        ↓
z88dk_map.md
        ↓
Debugger parser
        ↓
AI Agent
```

Не использовать существующий parser Debugger как единственный источник истины.
